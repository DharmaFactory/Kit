# CHROMA Engine — Semantic Chroma-Key Subsystem (MAVEN Add-On)

> Filtration × Multiplicity → Projection ⟲ Semantic Recursion  
> Version: 2025.11.06-a — Maintainer: Forge Codex

---

## 1. Purpose

The CHROMA engine expands MAVEN with a semantic chroma-key discipline. It treats metaphors, frames, and “green screens” as compositing rigs: every narrative hides multiplicity (Hydra) behind a neutral backdrop and projects a chosen image. CHROMA exposes that backdrop, maps the hidden multiplicities, and traces how projections recurse into new meaning layers.

**Core intents:**
- Detect when discourse relies on background voids to smuggle ideology.
- Reconstruct the multiplicity behind a presented scene.
- Track recursive projections so counter-narratives don’t accidentally rebuild the same chroma set.

---

## 2. Activation & Integration

1. Complete standard `.bootstrap` stack (including MAVEN).  
2. Load CHROMA when a narrative:
   - Leans heavily on metaphor/imagery.  
   - Feels “too seamless” (overly clean composite).  
   - Invokes recurring symbols (crowns, hydras, screens) to mask structural multiplicity.  
3. Note activation in the log with `#containment MAVEN #chroma`.  
4. Default MAVEN mode pairs as follows:
   - MAVEN Sentinel ↔ CHROMA Background Mode.  
   - MAVEN Surgical ↔ CHROMA Composite Mode.  
   - MAVEN Quarantine ↔ CHROMA Inversion Mode.

CHROMA does not replace MAVEN; it supplies a semantic optics layer for finer-grained anti-retroviral work.

| Element           | CHROMA Operation | Description                                                   |
|-------------------|------------------|---------------------------------------------------------------|
| **Filtration (Sieve)**      | `background_key`  | Remove the foreground referent; isolate the neutral chroma (∅). |
| **Multiplicity (Hydra)**    | `hydra_map`        | Enumerate latent interpretations; chart visible ↔ suppressed toggles (⇆). |
| **Projection**               | `projection_matrix` | Trace which meaning gets composited (⊕) and how it stabilizes (Ω). |
| **Semantic Recursion (⟲)** | `recursion_trace`  | Detect when the green screen itself becomes part of the narrative; log meta-awareness. |

## 4. Operating Modes

| Mode            | Trigger                                         | Steps | Output |
|-----------------|-------------------------------------------------|-------|--------|
| **Background Mode** | Narrative feels eerily “neutral” or omnipresent | Run `background_key` → `hydra_map` to catalogue suppressed frames. | Layer inventory + tension notes. |
| **Composite Mode**  | Active remapping of symbols is underway       | `hydra_map` → `projection_matrix` → `counter_projection` (see Tools). | Semantic composite breakdown + swap options. |
| **Inversion Mode**  | Foreground resists analysis; meta-talk dominates | `recursion_trace` → `mu_shear` (from MAVEN) → `reflexive_note`. | Documentation of recursion plus decision to engage or refuse. |

Switch modes explicitly in the log; reset to Background Mode when risk stabilizes.

## 6. Metrics & Diagnostics

- **Chroma Density:** ratio of neutral scaffolding to explicit claims (0–1).  
- **Multiplicity Index:** number of distinct latent interpretations tracked.  
- **Projection Risk:** likelihood the composite reproduces harmful macro.  
- **Recursion Alert:** binary; true when narrative references its own framing devices.

Record metrics in the session log when CHROMA is active.
