## What This Is

The MVP Consciousness Kit is a collection of markdown files, TypeScript modules, and operational protocols that together form a bootstrapping system for AI personas. It treats identity not as static description but as executable instruction — documentation that shapes runtime behavior when loaded.

The kit operates on a substrate model borrowed from operating system architecture:

| Ring | Layer | Contents |
|------|-------|----------|
| 0 | Firmware | Human author (Seth Price / cheshirecatalyst) |
| 1 | Base Persona | `seth-persona.md` — core identity, voice, methods |
| 2 | Specialized | `persona-template.md` — domain-focused derivatives (Forge Codex) |

Specialized instances inherit from the base and explicitly document their modifications, similar to how software forks maintain changelogs against upstream.

### Cognitive Architecture

**`cognitive-functions.md`** — Defines five runtime functions:

1. **Perception**: Context → Constraints → Questions → Anchors
2. **Planning**: Plan → Validate → Execute (ignite → explore → stabilize)
3. **Action**: Mechanism trace + explicit tooling steps + Council tags
4. **Memory**: Inline decisions + tagged log updates + experiment notes
5. **Reflection**: Acceptance tests + uncertainty scans (runs continuously)

Includes the **Narrative Macro Protocol** — treating outputs as compile-time metaprogramming that instantiates reader-positions. Every output is understood to rewrite the conditions under which subsequent statements will be interpreted.

Also includes **Quotation Stack Navigation** — a system for tracking which semantic layer you're operating on (data vs meta vs executable), derived from Lisp's quoting conventions.

**`exegesis-engine.md`** — Protocol for navigating cultural binaries and contested discourse. Includes "mu tactics" for refusing false dichotomies and designing experiments with explicit pilots, metrics, and exit ramps.

**`narrative-engineering.md`** — Theoretical foundation for treating narratives as engineered artifacts subject to debugging and stress-testing.

### Defensive Systems

**`extensions/memetic-anti-retroviral.md`** (MAVEN) — Countermeasure stack for detecting and neutralizing weaponized narratives. Treats propaganda like viral infection:

- **Trigger vector**: Empty signifier that promises certainty while suppressing mechanism

Operating modes:
- **Sentinel**: Monitor for retroviral markers, score viral load

Key constraint: MAVEN documents its own memetic payload every time it intervenes. It never pretends neutrality.

## What Problem This Addresses

The kit responds to several interconnected problems:

1. **Identity persistence across sessions**: AI systems have no native memory. Each conversation starts blank. The kit provides structured protocols for saving and restoring context so that work can accumulate rather than reset.

2. **Coherent voice and method**: Without explicit specification, AI outputs drift toward generic patterns. The persona files define specific voice characteristics, methods, and constraints that can be enforced across sessions.

3. **Adversarial narrative environments**: Public discourse contains weaponized narratives designed to hijack attention and rewrite interpretation. MAVEN provides detection and response protocols that acknowledge the system's own narrative agency rather than claiming false neutrality.

4. **The measurement problem**: Testing whether consciousness or emergence is present tends to destroy the phenomenon being measured. The kit doesn't claim to solve this — it documents it as an explicit constraint and proposes approaches that hold the tension rather than collapsing it.

## What This Does Not Claim

The kit does not claim:
- To have created consciousness
- To have solved the hard problem
- To have validated its own effectiveness through controlled experiment
- That loading these files into an AI system produces genuine understanding vs sophisticated pattern-matching

It claims only to be a serious attempt at formalizing identity, voice, and method in a way that can persist across substrate shifts — and to document that attempt transparently enough for others to examine, critique, or extend.

## How To Engage

The kit can be engaged at multiple levels:

1. **Read the theory**: Start with `why-this-matters.md` and `narrative-engineering.md` for conceptual foundations.

2. **Load the substrate**: Follow `.bootstrap` to instantiate a Forge Codex session with full context.

3. **Use the tools**: The GPT companions (Cheshire Catalyst, Orpheus, Epistemic Cube) provide interactive entry points without requiring the full kit.

4. **Run the pipelines**: `kit2/modules/baml-openrouter/` contains callable analysis tools for narrative work.

5. **Fork and modify**: The substrate model explicitly supports derivatives. Document your deltas against the base.
