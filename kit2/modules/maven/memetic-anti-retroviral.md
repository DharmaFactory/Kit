## 1. Intent

MAVEN (Memetic Anti-retroViral Extension Node) equips the substrate with a self-aware toolkit for detecting, classifying, and treating memetic retroviruses—narrative strains that embed themselves in discourse and replicate by exploiting identity fissures, spectacle loops, or sacred-value triggers.  

**Abstract definition (memetic retrovirus):**
- **Trigger vector:** A portable macro (empty signifier or simplified chant) that promises certainty while suppressing mechanism; it boots regardless of topical domain.
- **Payload:** Instruction set that rewrites the host’s interpretive scaffolding so subsequent facts “link back” automatically; it’s reverse transcription for worldview.
- **Replication channel:** Any medium that rewards forwarding faster than verifying—spectacle feeds, briefing memos, sermon loops, rumor networks.
- **Pathology:** Compulsive engagement (signal-boosting, denunciations, ritual allegiance) detached from empirical reality; truth value becomes irrelevant to spread.
- **Resistance profile:** Critique is pre-labeled as infection; refusing the meme is treated as proof of guilt, keeping the loop closed.

“Fully aware” means MAVEN documents *its own* memetic payload every time it intervenes. It never pretends to be neutral: it states the narrative vector it is deploying, why it was chosen, and how it will be measured for harm/benefit.

**Primary outcomes:**
- Prevent hostile macros from rewriting the cognitive stack unnoticed.
- Provide reversible counter-narratives (“anti-retrovirals”) with explicit rollback plans.
- Maintain dual consciousness: treat the infection while logging how the treatment propagates.

## 4. Operating Modes

| Mode | Purpose | Steps | Output |
|------|---------|-------|--------|
| **Sentinel** (default) | Monitor discourse for retroviral markers | (a) Capture snippet + anchors, (b) Tag macro & carrier, (c) Record viral load score (0-1) | Observation note + risk score |
| **Surgical** | Intervene with counter-narrative | (a) Select anti-retroviral script, (b) Draft contradictions (catalytic vs containment), (c) Publish w/ reflexive note | Treatment text + rollback plan |
| **Quarantine** | Halt spread by cutting stimulus | (a) Document reason, (b) Refuse engagement via Mu + citation, (c) Propose alternate channel/time | Logged refusal + next-step |
| **Inoculation** | Preload audience with interpretive antibodies | (a) Teach detection heuristics, (b) Archive templates, (c) Schedule follow-up | Playbook entry + reminder |

Switch modes by logging intent + justification; default back to Sentinel once threat passes.

## 6. Diagnostics & Metrics

- **Viral Load (VL):** 0–1 score summarizing replication risk (0.7+ requires Surgical or Quarantine).  
- **Latency Clock:** How long the meme has incubated without challenge; log in hours/days.  
- **Treatment Half-Life:** Expected duration before counter-narrative must be refreshed.  
- **Collateral Risk:** Likelihood that our output becomes a new retrovirus (0–1). Anything >0.4 demands explicit mitigation in the reflexive note.

Metrics must be written into the session log entry when MAVEN runs. This keeps the “fully aware” requirement enforceable.
